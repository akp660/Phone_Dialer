📱 Phone Dialer Flutter Application

## 📌 Overview
The **Phone Dialer** is a Flutter application that allows users to:
- Dial phone numbers directly from the app.
- Save and manage contacts.
- View call history.
- Make calls using the native dialer functionality.

## 🚀 Features
- 📞 **Dial Numbers**: Enter and call phone numbers.
- 📂 **Save Contacts**: Store and manage contact details.
- 📜 **Call History**: View recent calls made from the app.
- 🌐 **Cross-Platform Support**: Works on both Android and iOS.

## 🛠️ Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Provider / Riverpod (Optional)
  
## 📲 Installation
### Prerequisites
- Install [Flutter](https://flutter.dev/docs/get-started/install)
- Set up an emulator or connect a real device

### Steps
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/phone_dialer_flutter.git
   cd phone_dialer_flutter
   ```
2. Install dependencies:
   ```sh
   flutter pub get
   ```
3. Run the app:
   ```sh
   flutter run
   ```
